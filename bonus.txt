Bonus 1: Logging system with configuration file
------------------------------------------------
- Implemented a full logging system (Logger class) that writes debug messages into "debug_log.txt" file.
- The additions from the bonus in EX1: We added explanations to the reasons algorithms choose their actions, and the board after each turn, and of course
we now take care of more than one tank for each player.
- Logging is activated only if "log_config.txt" contains the line ENABLE_DEBUG_LOG=true.
- Otherwise, the Logger remains inactive and does not create any file.
- How to check: After the game, "debug_log.txt" will be generated containing debug logs for all major game actions.

Bonus 2: Visual Simulation
---------------------------
- Developed a visual simulation (Python script named visual.py) that displays the progress of the game based on the log file generated during the game.
- Visual.py reads the initial map and the moves from the log file and shows the tanks, walls, mines, and shells moving and interacting on the board graphically.
- The addition for the bonus in EX1: We now base the simulation on the debug file and not the input anc output files,
we now have 1 or 2 indicating the wall's hp, added some effects on explosions, and of course we now support more than one tank
for each player and also have effect for a tank that asks for battleinfo.
- How to check: run the provided visual.py script after running the game like that: python3 visual.py debug_log.txt
- Visual.py is external to the game execution (does not affect gameplay) and is optional.

Bonus 3: Automatic Testing using GTest
------------------------------
- We used GoogleTest (gtest) to validate our tank game logic with unit tests.
- The tests check game end conditions, such as stopping after a maximum number of turns, ending after 40 turns without shells, and handling special collision cases.
- To run the tests, update the paths in the Makefile to your local gtest location, build with make test_game, and execute ./test_game to see the results.
